## What is FiveM Jobs Creator?

[FiveM Jobs Creator](https://vertexmods.com/jobs-creator/builder) is a **free, browser-based visual editor** that lets you configure FiveM server jobs in minutes — without touching a single line of Lua manually.

Fill in a form, pick your framework, hit export — and you get a production-ready job config you can drop straight into your server.

> **[Try it now — no account required →](https://vertexmods.com/jobs-creator/builder)**

---

## Features

- **Visual form interface** — no guesswork, every field is labeled and explained
- **Multi-framework export** — one config, four frameworks (ESX / QBCORE / QBox / OX_CORE)
- **Grades & permissions** — define unlimited job grades with salaries and permission levels
- **Vehicles & equipment** — attach vehicles and loadouts to specific grades
- **Duty system** — on/off-duty toggling built into every exported config
- **Blip & marker support** — configure map blips and 3D markers visually
- **One-click copy** — exported Lua is formatted and ready to paste
- **100% free** — no login, no paywall, no ads blocking the tool
- **Instant preview** — see your config structure update in real time as you type

## How to Use

### 1. Open the Builder

Go to **[vertexmods.com/jobs-creator/builder](https://vertexmods.com/jobs-creator/builder)** in any browser. No installation needed.

### 2. Fill in Your Job Details

| Field | Example |
|-------|---------|
| Job name | `police` |
| Job label | `Los Santos Police Department` |
| Default duty | `true` |
| Blip sprite | `60` |
| Blip color | `29` |

### 3. Add Grades

Click **"Add Grade"** and fill in:
- Grade number (0, 1, 2, …)
- Grade name (`Recruit`, `Officer`, `Sergeant`, …)
- Salary (in-game currency per pay period)
- Is boss grade? (yes/no)

### 4. Choose Your Framework

Select your target framework from the dropdown:
- **ESX** — classic, most-used
- **QBCORE** — modern, QB ecosystem
- **QBox** — next-gen QB variant
- **OX_CORE** — performance-first, resource-based

### 5. Export & Copy

Click **"Generate Config"** and copy the formatted Lua output. Drop it into your resource folder.

## Example Output

Below is a sample police job exported for **ESX** from the [Jobs Creator builder](https://vertexmods.com/jobs-creator/builder). The `starter-configs/` folder in this repo contains ready-to-use examples for all frameworks.

```lua
    },
})
```

## FAQ

**Is this tool really free?**
Yes. The [FiveM Jobs Creator](https://vertexmods.com/jobs-creator/builder) is completely free to use, forever. No account required.

**Does it work with the latest ESX/QBCORE versions?**
Yes. The builder targets `es_extended` ≥ 1.9, `qb-core` ≥ 1.3, `qbx_core` ≥ 1.x, and `ox_core` ≥ 2.x. Configs are updated whenever frameworks release breaking changes.

**Can I add custom metadata to grades?**
Yes — there is an "Advanced" section in the builder that lets you add arbitrary key/value pairs to any grade. This is useful for custom ESX plugins or OX permissions.

**How many grades can I add?**
Unlimited. The builder has no artificial cap on grade count.

**Can I import an existing job config?**
Not yet, but it's on the roadmap. For now, use the builder to recreate the job and export fresh.

**Where do I report bugs or request features?**
Open an issue on this repo or contact us through [vertexmods.com](https://vertexmods.com).

**Can I contribute starter configs?**
Absolutely. Fork this repo, add a Lua file to `starter-configs/`, and open a PR. Configs for EMS, mechanic, taxi, and other common jobs are especially welcome.
